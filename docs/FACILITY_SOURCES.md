## Evidence and repeatable next step

`data/facility-verification/*-web-extract.txt` are line-numbered web-reader extracts of the layer directory pages, **not original response bytes**; `manifest.json` records source URLs, bounds on retrieval time, and SHA-256 of the saved extracts. Their hashes check local integrity, not reproducibility against changing server responses or reader formatting. Other links above were inspected through the web reader and are not cached. The known cache timestamp is an upper bound, not an invented exact retrieval time.

When network/DNS permits, run `python3 data/facility-verification/fetch.py` from the project root. It requests each metadata JSON and at most two features, asks for WGS84 output, checks response shape and caps each response at 2 MB. It stores only successful raw responses and writes `raw-manifest.json` with exact request URL, UTC retrieval timestamp, bytes, HTTP status and SHA-256. These are bounded samples, not a complete coverage test. Confirm successful queries without credentials, inspect service errors, compare county counts/extents and source terms, then perform a separate complete acquisition and geographic validation before claiming statewide support. A future full pull must handle pagination and missing geometries; it is not part of this verification.
