# Common ground frontend assets

`basemap.json` is a locally customized copy of the OpenFreeMap Positron style fetched on 2026-11-07 from https://tiles.openfreemap.org/styles/positron. It retains the provider's remote vector tile, sprite and glyph sources and their attribution. Only visual paint values were changed. The map displays OpenFreeMap, OpenMapTiles and OpenStreetMap attribution. No bulk tile download or offline tile cache was created. Provider docs: https://openfreemap.org/quick_start/.

DM Sans (400/500/600/700) and DM Serif Display (400) were downloaded from Google Fonts on 2026-11-07 and are served locally. Original SIL Open Font License texts are alongside the fonts (`fonts/dmsans-OFL.txt`, `fonts/dmserifdisplay-OFL.txt`). Google Fonts source families: https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/dmserifdisplay. No font CDN request is required at runtime.

The contour identity and favicon are original inline SVG artwork. Synthetic fixture geometries are generated by frontend code and labeled as synthetic; they are not geographic evidence.
